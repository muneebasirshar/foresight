Optional add-on

Voice Check

A short, opt-in spoken task — a verbal Stroop or a brief free-response prompt — that reads vocal biomarkers linked to fatigue and cognitive load: speech rate, pause patterns, pitch variability. Best suited for roles where voice clarity already matters, like dispatch and call center. Raw audio is never stored — only the derived score, processed on-device or transiently, behind its own explicit consent flow. Priced separately from the per-employee tiers.
